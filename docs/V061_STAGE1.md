# V061 阶段一：政策组件化

本阶段将政策表示为可审计的 `policy_components` 对象，包含三个当前生效的组件：

- `information_delivery`：是否发送主动信息及发送日；
- `access`：求助门槛倍率；
- `service`：服务容量和开放频率。

三种条件的默认行为保持不变，正式配置文件现在显式保存这三个组件。组件对象会进入 LLM 的 `policy` 上下文，也用于信息送达、求助机会、服务容量和开放日的确定性规则。后续可以只改变一个组件开展消融实验。工作人员跟进机制尚未实现，避免把计划功能误写成当前能力。

本阶段只改变政策表示和规则入口，不改变既有学生状态公式。结果仍属于未经校准的合成情景。
