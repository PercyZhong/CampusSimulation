# V064：校园互动环境与行为轨迹

本阶段面向功能真实性扩展，不接入真实人工数据，也不改变参数校准方式。目标是让学生行动发生在可观察的校园环境中，并让行为轨迹能够被复核。

## 已实现的第一步

- 每名学生每天获得确定性的课程上下文：`course_id`、`venue`、`section`；上下文由种子、日期和学生 ID 生成，因此同一协议可复现且不同学生可以处于不同课程/场所。
- `course` 信息现在同时包含当天 `academic_load` 和该学生的课程上下文，LLM 决策可读取这些字段。
- 学生完成 `attend` 时生成 `class_attendance` 互动记录，保存日期、学生、同学、课程和场所；同学获得很小的联结更新，形成可追踪的课堂接触。
- `attend` 完成事件记录课程上下文和确定的同学，便于从 `events.jsonl` 重建行动轨迹。
- 汇总增加轨迹指标：行动切换次数、发生过互动的不同同伴数、课堂互动次数。

## 行为轨迹评估方向

后续轨迹评估将从事件序列计算：行动转移矩阵、连续行动长度、同伴重复关系、课程场所暴露、求助前后的行为变化、支持后的恢复轨迹和互动网络边变化。每项指标都以事件日志为来源，并保留日期和主体 ID，避免只比较最终均值。

## 下一步功能增量

1. 增加课程日程和共享场所，使同一课程的学生集合由环境生成，而不是只按全体学生抽取同学。
2. 增加小组活动、宿舍/社团等多种互动场景，并区分主动发起、被动接触和拒绝。
3. 将课堂互动、同伴交流和工作人员接触统一成互动事件模式，记录发起者、对象、场所、回应和结果。
4. 在第七阶段报告中加入转移矩阵、关系重复率、轨迹长度和互动网络指标。

这些扩展仍属于合成校园模型；真实性来自更完整的可观察机制和轨迹，而不是对现实学生行为的校准声明。
