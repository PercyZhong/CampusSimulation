# V062 阶段一：状态驱动同伴交流与情绪反馈

本阶段优先改进原计划的第二、第五阶段。

- 离线同伴交流由两轮固定模板升级为四轮、可复现的双方 agent 对话。对话内容读取发起者和同伴的压力、联结和情绪状态，并根据双方既有社交记忆生成回应；同伴事件仍记录双方和完整对话，避免引入网络调用。
- `accept_support`、`rest` 和 `peer` 行动现在即时更新相关压力、情绪、恢复或联结变量；每日结算继续应用有界的负荷和恢复公式。所有变化都经过 `[0,1]` 截断，并有方向性测试。

这些规则是可审计的合成假设，不是心理量表或真实对话数据。LLM 对话后端、长期记忆和经验校准仍未实现。Linux 验收结果在代码同步后补充。
