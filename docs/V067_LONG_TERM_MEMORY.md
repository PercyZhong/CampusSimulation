# V067 长期记忆

每个学生保留 `long_term_memory`，包括已完成行动及邀请、回应的累计次数，以及按伙伴区分的接触次数、最近回应、最后接触日和显著度。最近五条行动与社交记录继续保留为短期记忆。

邀请、伙伴回应和完成对话更新双方的伙伴摘要。伙伴显著度在日终按 `0.9 ** 间隔天数` 衰减，低于 `0.05` 的伙伴摘要从学生决策状态中移除；累计行动次数不衰减。事件日志和每日 `student_state.memory_*` 快照保留可审计事实。

规则驱动的 `peer` 阈值使用近期仍显著的接受或拒绝经历，影响幅度限制在正负 `0.04`。LLM 决策获取长期摘要，四轮对话获取当前伙伴摘要。新的提示词版本为 `long-memory-v1`。`summary.json.long_term_memory` 给出保留伙伴摘要的学生数、摘要总数和累计行动次数。

这些是模型内部合成记忆，不代表真实学生的心理记忆。机制改变了行动选择，因此新运行需与旧版评估矩阵分开比较。
