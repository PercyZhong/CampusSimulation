# V063 阶段一：同伴行动提示词与决策日志

此前固定种子 11、40 名学生、10 天的 Qwen `qwen-plus` 基线运行完成了 400 次模型决策，但没有选择 `peer`。这只说明该次模型输出的行动分布，不证明 `peer` 在决策时不可选，也不能单凭一次运行判断原因。

本阶段将提示词标记为 `peer-context-v1`，说明 `peer` 会发起一次具体的四轮同伴交流，并提醒模型在联结偏低或近期缺少社交接触时，将其与其他可用行动一起考虑。提示词仍要求从 `policy.available_actions` 中自主选择，不设置 `peer` 配额或改写模型选择。

每条成功的 `model_decision` 事件现记录精简的 `decision_context`：当时可选行动、联结、压力、情绪、是否有待处理请求、最近自身 `peer` 次数和社交记忆条数；事件同时保留原有政策上下文、模型名称和用量。不会写入 API 密钥或完整模型原始回复。这些字段用于区分“`peer` 未开放”和“已开放但模型没有选择”。

本阶段的自动化测试使用本地假模型请求，验证提示词和导出事件字段。Linux 环境运行结果为 30 个测试通过，Ruff 与 `git diff --check` 通过。

真实 Qwen 验收使用 `qwen-plus`、固定种子 11、40 名学生和 10 天，输出目录为 `runs/v063-qwen-baseline-seed11-10d`，场景版本 `854bdfd`。运行完成 10 步，诊断错误 0，发生 400 次网络及付费模型调用。逐条检查事件后，400 次模型决策均开放 `peer`，其中 232 次选择 `peer`，232 次实际完成；全部完成事件均包含四轮对话，提示词版本均为 `peer-context-v1`。这确认了行动选择和执行链路有效；四轮对话文本仍由离线语言后端生成，并非由 Qwen 生成。
