# V060 阶段一：具体同伴互动

本阶段把原来的抽象 `peer` 行动扩展为可审计的同伴互动事件。学生从自己的环形社交边中确定一名同伴，事件记录 `partner` 和两轮离线对话；发起者的 `connection` 增加 0.045，被互动同伴增加 0.02。对话使用命名随机流和离线模板生成，因此不增加 API 调用并且可以复现。

本阶段完成内容：

- 同伴行动记录明确的互动对象；
- 记录双方各一轮的短对话；
- 互动对象获得连接度更新；
- 增加语言层可复现性测试和 Society0 集成测试；
- 保留服务容量、政策和学生状态的现有规则。

本阶段尚未实现长期记忆、LLM 生成对话或多轮社交网络传播。实验结果仍属于未经校准的合成情景。
